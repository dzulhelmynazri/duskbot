check a download.

every release lists each installer's sha-256 fingerprint in SHA256SUMS (open it). yours should match exactly.

mac

shasum -a 256 ~/Downloads/MadaniBot.dmg

windows (powershell)

Get-FileHash $HOME\Downloads\MadaniBot-setup.exe -Algorithm SHA256

linux

sha256sum ~/Downloads/MadaniBot-amd64.deb
